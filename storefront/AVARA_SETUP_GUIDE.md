# AVARA setup guide

## What AVARA needs

AVARA needs either **Ollama running locally** or compatible **AI-provider API keys**. AVARA may open without every provider, but features that depend on an unconfigured AI service will not work. Provider usage charges are separate from the AVARA plan.

## Install

1. Sign in to the AVARA storefront using the account used for your cash order.
2. After approval, open **Your orders** and choose **Download AVARA**.
3. Extract the downloaded ZIP into a folder you control.
4. Read the release README included in the ZIP.
5. Run the installer or launcher supplied with that release.

## Configure AI

- For local AI, install Ollama from <https://ollama.com/> and download the model recommended in the release notes.
- For cloud AI, enter compatible provider API keys only in AVARA's local settings or approved environment configuration.
- Google and other integrations require their own authorization.

Never email passwords or API keys, paste them into the storefront, or include them in screenshots.

## Verify

Confirm that AVARA starts, the selected AI connection reports online, and a simple chat works. Then configure optional features such as Phone Remote, Google integrations, or voice.

If the approved download is missing, refresh your order status and sign in again. Contact AVARA support with the order number only—never with your password or API keys.
