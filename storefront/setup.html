AVARA setup guide

Download and install

  • Download AVARA from the download section. There is one installer per system and it is the same for every plan; no account or order is needed to download.
  • Windows: run AVARA-…-windows-setup.exe and follow the installer. It installs for your Windows user only.
  • Mac: requires Apple Silicon and macOS 14 or later (Apple menu → About This Mac). Open the DMG, drag AVARA to Applications, eject the disk image, and open the installed app.
  • When AVARA opens it shows Choose your plan. Pick Basic, Pro, 6-Month Basic or 6-Month Pro. AVARA shows a one-time code such as AVR-7F3K-92QD.
  • Send that code to the AVARA owner on WhatsApp and pay by cash or UPI. Keep AVARA open and online; it unlocks by itself once the owner approves and shows your plan and expiry date.
  • The code works once, only on this computer, and expires after 48 hours if it is not approved. You can change the plan before approval; AVARA then shows a new code and the old one stops working.

The packaged app includes Python and its application dependencies. You do not need to install Python or Node.js separately for the EXE/DMG release. Ollama is a separate optional installation if you choose local AI. A Windows installer cannot run on macOS, and a Mac DMG cannot run on Windows.

Choose one AI option

  • Groq: create a key at Groq API Keys.
  • Gemini: create a key at Google AI Studio.
  • Local AI: install Ollama, download a compatible model from its model library, and keep Ollama running.

Use the welcome setup or Settings → AI & voice to choose your provider, save its key or model, and test a simple chat. You need only one AI option. Groq/Gemini require internet and have their own limits or charges. Local models need sufficient computer resources. Optional voice, image, video, Google, and other integrations have separate setup requirements.

Enter API keys only in AVARA's local setup/settings. Never send passwords, activation tokens, or API keys in public messages or screenshots.

Approval and subscriptions

Monthly Basic is ₹150 and monthly Pro is ₹200. Six-month Basic is ₹1,000 and six-month Pro is ₹1,400. Plans last 30 or 180 days from approval. Renewing early adds the new term to your current expiry.

AVARA checks your plan online and keeps a signed copy of the last answer, so it keeps working offline for a while (up to 7 days, never past your plan's expiry). Then it needs to re-check online. The owner can pause, continue, renew, cancel, change or extend a plan. To renew or change your plan, open AVARA's plan screen and choose a plan to get a new code.

Already a customer? Install the new version over the old one on the same computer and Windows/Mac user. AVARA keeps your existing plan automatically. A reinstall after deleting AVARA's data folder, or a new computer, needs a new code.

Source ZIPs only

Older source ZIPs require 64-bit Python 3.11 or newer. Use the Windows or macOS Python download page. Use a Python version supported by the release dependencies; the newest version is not automatically compatible with every package. On Windows enable Add Python to PATH. Extract the entire ZIP and follow START_HERE.txt or the supplied START_AVARA_WINDOWS.bat / START_AVARA_MAC.command launcher. These steps do not apply to packaged EXE/DMG downloads.

Mac permissions and testing

Screen understanding, microphone, camera, and app control may need the corresponding macOS permissions. Review each request yourself. Windows-specific automation is not guaranteed on macOS. Mac availability in the storefront does not mean every feature has been tested on both Mac architectures.

Troubleshooting and uninstall

  • Download not available: the release may still be uploading. Try again later or contact the owner.
  • Mac compatibility: the current release requires Apple Silicon and macOS 14 or later.
  • Plan check cannot connect: confirm internet access and wait a minute for the service to wake. If it persists, send the owner your code and a redacted log.
  • AI offline: test your chosen provider, key, quota, or running Ollama model.
  • Startup failure: read AVARA's log under Local AppData/AVARA/logs on Windows or Library/Application Support/AVARA/logs on Mac. Share only a redacted error excerpt.
  • Unrecognized publisher warnings: download AVARA only from this website. Stop if the source is uncertain; do not disable system protection.
  • Windows packaged install: use Settings → Apps → Installed apps and the AVARA uninstaller if provided by your release. Mac: quit AVARA and remove its app from Applications. Saved user data may remain.
  • Older source ZIPs: use the included UNINSTALL_AVARA_WINDOWS.bat/UNINSTALL_AVARA.ps1 only for that installation. Do not remove shared Python, Node.js, or Ollama just to uninstall AVARA.

Before relying on optional features, verify them in Settings/Diagnostics and perform a small real action. A successful app launch does not prove every connected service works.
