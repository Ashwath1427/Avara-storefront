AVARA Setup Guide

This guide explains what you need before running your approved AVARA download.

AI requirement: AVARA needs either Ollama running locally or compatible AI-provider API keys. AVARA can open without every provider, but features that depend on an unconfigured AI service will not work.

1. Download your approved plan

Sign in on the AVARA website using the same account used for your cash order. In Your orders, choose Download AVARA. The download is available only after approval.

2. Choose local AI or provider APIs

For private local use, install Ollama and download the model recommended in the release notes included with your ZIP. Alternatively, configure API keys for the AI providers you choose to use. Provider charges are separate from the AVARA plan.

3. Keep credentials private

Enter API keys only in AVARA's local settings or approved environment configuration. Never email keys, paste them into the storefront, or place them in screenshots. Google and other integrations require their own authorization.

4. Install and start

Extract the ZIP into a folder you control. Read the included release README, then use the installer or launcher included in that release. Allow Windows permissions only when you recognize the AVARA release you downloaded.

5. Verify the basics

Confirm AVARA starts, the selected AI connection reports online, and a simple chat works. Then configure optional phone remote, Google integrations, voice, or other plan features.

Troubleshooting

If a download is missing after approval, refresh the order status and sign in again. If an AI feature is offline, confirm Ollama is running or that the relevant API key is valid. Contact AVARA support with your order number—never with your password or API keys.
