AVARA Setup Guide

This guide explains what you need before running your approved AVARA download.

Before you begin: Install 64-bit Python and choose at least one AI option: a Groq API key, a Gemini API key, or a local model running in Ollama. You do not need all three. Internet is needed for first-time installation and activation.

1. Download your approved plan

Sign in on the AVARA website using the same account used for your cash order. In Your orders, choose Download AVARA. The download is available only after approval.

2. Install Python

Download the latest stable 64-bit Python for Windows from python.org. During installation, enable “Add Python to PATH” if offered. AVARA requires Python 3.11 or newer. If the newest release cannot install an AVARA dependency, try Python 3.11 or 3.12.

3. Choose one AI option

  • Groq: Sign in to Groq API Keys and create a key.
  • Gemini: Create a key in Google AI Studio.
  • Ollama: Download Ollama, install it, and download a compatible local model from the model library. Keep Ollama running and select the installed model in AVARA.

Groq and Gemini require internet access. Provider usage limits or charges may apply separately from your AVARA plan. Local model performance depends on your computer.

4. Install and start AVARA

Extract the entire downloaded ZIP into a folder you control. Open the extracted folder and double-click START_AVARA_WINDOWS.bat. The first start installs required packages, so keep the window open and stay connected to the internet. Read START_HERE.txt in the downloaded folder for release-specific instructions.

5. Activate and configure AI

Send the AVARA owner the one-time code shown in the app and your order number. Keep AVARA open while it checks for approval. Once unlocked, use the welcome setup or Settings → AI & voice to select Ollama, Groq, or Gemini. Paste a cloud API key there if you chose one, save the settings, and test the connection with a simple chat.

AVARA for Mac

The Mac edition is in testing. Once it is available, approved orders will show a separate Download AVARA for Mac button. Some computer controls and integrations are Windows-specific and may not be available on macOS.

Keep credentials private

Enter API keys only in AVARA's local setup or settings. Never email keys, paste them into the storefront, or include them in screenshots. Google Workspace and other integrations require their own authorization.

Troubleshooting

If a download is missing after approval, refresh the order status and sign in again. If an AI feature is offline, confirm Ollama is running or that the relevant API key is valid. Contact AVARA support with your order number—never with your password or API keys.
